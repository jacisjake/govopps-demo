# GovOpps — Studio

Accept on Strong (`Begin Application`) or Maybe (`Go`) creates a **workspace** for one opportunity. Weak cannot open a studio until it promotes. Poor is never offered.

No live submit to SAM in v1.

## Workspace

Points at: session, freeze, the accepted score record.

## Checklist

Each item is data, not copy:

| field | from |
|---|---|
| id, label, class | scoring §7: registration · read · gap-closing · upgrade · prepare · engage |
| status | open · in_progress · done · blocked |
| tool | narrative · evidence · deadline · none |
| source | requirement_gap or next_steps |

## Tool shelf (v1)

| Tool | Writes |
|---|---|
| **Narrative** | Draft text onto a `prepare` item |
| **Evidence** | Stated / uploaded proof onto a gap item |
| **Deadline** | Read-mostly (`close_date`, `days_remaining`). May mark the timing item done or blocked. Cannot invent a due date. |

McKenna may help complete the **open** item. She does not invent solicitation URLs.

## Flow

Map (default after score) → Accept → studio. The map stays reachable. Header stats stay on the map, not inside the folder.
